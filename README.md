Simple Weather slack bot


## Commands

/mwb-ping
	

pings Mr weather

/mwb-weather
	

Current conditions in a city

/mwb-forecast
	

5-day, 3-hour forecast

/mwb-week
	

Daily highs/lows for the next 5 days

/mwb-compare [city1] | [city2]
(remember the | or it wont work)
	
Side-by-side current weather
